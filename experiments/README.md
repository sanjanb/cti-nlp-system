# Experiments Folder

This folder is for safe experimentation with new models, features, and data improvements. You can copy scripts and datasets here to try new ideas without affecting the main project.

## Suggested Workflow

- Copy any script you want to modify into this folder.
- Use a subset or copy of your data for quick iteration.
- Document each experiment in this README or in separate notes.

## Example Ideas

- Data augmentation
- Advanced feature engineering
- Trying new models or hyperparameters
- Handling class imbalance

---

**Keep your main codebase stable by doing all risky or experimental work here!**
